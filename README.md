 Selected Projects

### 1. PPG-Based Atrial Fibrillation Detection
Developed a machine-learning pipeline to identify atrial fibrillation from photoplethysmography (PPG) signals.
- Butterworth filtering, normalization and signal segmentation.
- FFT-based feature enhancement.
- 1D Convolutional Neural Network using Python and TensorFlow/Keras.

### 2. Wireless Power Transfer for Implantable Medical Devices
Designed and experimentally evaluated a resonant inductive wireless power-transfer system.
- Modified Royer oscillator with frequency stabilization.
- ESP32-based monitoring and ANSYS Maxwell electromagnetic analysis.
- Achieved approximately 4 W output with 34–38% overall efficiency.

### 3. COPD Diagnostic–Therapeutic System
Developed an integrated concept combining respiratory measurement and capacitive RF hyperthermia.
- Ultrasonic spirometry for FVC and FEV1 measurement.
- Real-time respiratory signal acquisition.
- RF hyperthermia system operating at 13.56 MHz.
- Focused on affordable healthcare solutions for resource-limited settings.

### 4. Automated Saline Bag Monitoring System
Built an Arduino-based monitoring system for continuous saline bag measurement.
- Load cell and HX711-based measurement.
- Real-time monitoring and feedback.
- Approximately ±1.5% measurement accuracy.
